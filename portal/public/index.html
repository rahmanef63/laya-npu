How a decision happens

Two stages, both on the NPU, neither touching a network. The model only perceives; plain Python decides. That split is the whole design.

Input Audio or text A voice note, a ticket body, an email, a file from a watched folder. mic · textarea · folder · POST
Stage 1 · optional Whisper transcription Audio becomes text. Any format, because ffmpeg ships with it. 57x realtime · int8 · NPU
→
Stage 2 Laya reads it 421M classifier answers the questions you defined. Probabilities only, never prose. 29 ms · int8 · NPU
Output Typed answers One value per question: a choice, an ordinal score, or P(yes). JSON · no parsing
→
Stage 3 · yours Policy in Python A dict and a few if statements map answers to an action. You own this part. tasks.py
Result An action Route to billing, hold for approval, block the prompt, file the receipt. 0.9 s audio → action

The model deliberately does not choose the action. Asking it directly scores 2/12 on our test set; asking its questions and deciding in Python scores 22/22. It reads text well and knows your policy not at all.

Why this exists

The NPU is idle

Windows uses it for Studio Effects and live captions. That is roughly it. There is no general-purpose path from "I have a neural processor" to "I have a program that decides things".

Cloud calls cost money per decision

Routing a ticket, gating a prompt, labelling an issue: each one is a metered API call today. A 421M decision model on hardware you own makes them free.

Text models cannot do this well

Asking an LLM to output JSON for a 4-way choice means parsing, retries and hallucinated labels. A decision model returns probabilities and no prose.

Questions

Does this send my data anywhere?

No. Inference runs locally in the OpenVINO runtime. If you link a device ID, the app sends a small heartbeat every five minutes containing the ID, the OS, the app version, and which devices compiled. No text, no prompts, no file paths, no credentials.

What if my machine has no NPU?

It still works. The app falls back to the integrated GPU or the CPU. On a Core Ultra 9 386H the NPU answers in 66 ms, the GPU in 43 ms, the CPU in 443 ms — same answers.

Can I use my own hosted endpoint instead?

Yes. The Compute page has a BYOK tab: point it at any server that speaks the Jev System One protocol with your key. The key stays server-side and is never written to disk.

Does it handle languages other than English?

Not yet. The shipped checkpoint is English and scores near zero on non-Latin scripts while still reporting high confidence, which is a silent failure. The multilingual checkpoint has never been exported to OpenVINO.

Why does the model not pick the action?

Because it scores 2/12 at that and 22/22 at answering its own preset questions. Reading text is the model's job; your policy is yours. Every action in the app comes from a small Python rule table you can edit.
